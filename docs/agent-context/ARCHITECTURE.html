04Mobile & remote-access chain — the gap forkbase fills

✅ upstream README: "Mobile requires Superset Pro, iOS 26 or later, and a computer with Remote Access enabled."

Upstream today

📱 iPhone only · ☁ their hosted Pro cloud · 💰 subscription-gated · 🐧 Linux desktop "experimental" · 🪟 Windows none.

Forkbase tomorrow

🤖 Android free (in-repo Expo app enabled) · ☁ self-hosted compose · 💰 zero gate · 🐧 Linux first-class · same desktop code.

Why this is a distribution problem, not an architecture problem: both the mobile client (apps/mobile ✅ Expo/RN) and the entire cloud stack (api/gate/relay/realtime/review-host/usercontent ✅ in repo) are open. The paywall lives in their hosted accounts — 🔶 exact gate location = Phase 1a.

07The fork model — seams, not edits

How "own direction" survives upstream shipping daily. Binding rule D7.

upstream superset-sh/superset

main · ships daily · ~500 open PRs

→ merge weekly →

forkbase diff (the only edits)

① white-label patch script (names · icons · bundle IDs · update feed · telemetry)
② packages/forkbase-* — new code, own license
③ Android enablement in apps/mobile
④ self-host compose + un-gate

→

mrvigneshvt/forkbase main

generic Linux fixes flow back upstream as PRs — every merge shrinks the diff

Conscious hard-fork moment: track upstream until the beta is stable, then pick a divergence commit and own it (security cherry-picks only). Drift-into-divergence is forbidden.

08License layer

Inherited code — stays Elastic License 2.0

Cannot be relicensed (ever). Use, fork, modify, self-host: free. One prohibition below.

Forkbase's new code — author's choice

Android additions, packages/forkbase-*, self-host tooling: any license on top.

"use it, fork it, modify it, self-host it for your team. The only thing off the table is repackaging Superset itself as a service you sell to others." — upstream README ✅
Consequence for the open beta: publish freely, distribute the Android APK freely, self-host freely. If forkbase is ever commercial, the repackaged-fork-as-a-hosted-service route is prohibited — own additions can be monetized freely.
